## Features

-   Easy to install
-   Built in plugins library
-   All Browsers Support: Run YovariX in your Browser via UserScript
-   Custom CSS and Themes: Inbuilt css editor with support to import any css files (Example [Catppucin-mocha](https://raw.githubusercontent.com/SevaGetz/YovariX/refs/heads/main/catppuccin-mocha.css))

## Install
> [!NOTE]
> Some plugins are not optimised for mobiles but it will be fixed soon
1. Install [**Tampermonkey**](https://www.tampermonkey.net/) (Recommended) or [**Violentmonkey**](https://violentmonkey.github.io/)
2. Click on this link: [**Install mod**](https://raw.githubusercontent.com/SevaGetz/YovariX/refs/heads/main/dist/YovariX.user.js)
3. Your Userscript manager will automatically open a new tab showing the script details.
4. Click the **Install** button.

## Plugins

* **embedLink** — Automatically modifies links copied via "Share → Copy link" using an embed fixer (like fixupx.com).
* **gifFav** — Adds a "Favorites" tab to the GIF picker and star icons to GIFs in the picker and tweets.
* **sidebarHide** — Hides selected items from the X sidebar, including Explore, Grok, and Premium.

...and more plugins coming soon!

## Disclaimer

<details>
<summary>Using YovariX violates X's terms of service</summary>

Client modifications and extensions are against X's Terms of Service.

However, all plugins built into YovariX are completely harmless, and you shouldn't get banned for using them. 

Regardless, if your account is very important to you and it getting disabled would be a disaster for you, you should probably not use any client modifications (not exclusive to YovariX), just to be safe.

Additionally, once launched, make sure not to post screenshots with YovariX in threads or communities where you might get reported or banned for it.
